# Memory Rush
A simple Game to test your memory
## Description
The game is built in python. The game is very simple, when you get the window to play, after clicking the start button, You must keep watching the color pattern the game
produces and you must click on the same pattern color to keep up your score. If you miss a color your game ends and the points will move back to 0 and you should restart
the game by clicking the restart button

# Getting Started
### Dependencies
- It can be run on any OS of any version
- There is no need to download any library in prior
- Only one .exe file must be downloaded as instructed below
### Installing
- Download the Memory.Rush.exe file from latest Release
- Save fill to your preferred location
### Executing Program
- Navigate to the folder having Memory.Rush.exe
- Double click the executable to launch Memory Rush
# Help
